# 🏥 Hospital Management System

A web-based **hospital management system** with four role-based portals and a public landing page. Built with PHP and MySQL, inspired by my ICT attachment at Machakos Level 5 Referral Hospital.

## ✨ Features

- **Four role-based portals:** each type of hospital staff member gets their own dashboard and tools
- **Public landing page:** an informational front page for visitors and patients
- **Database-driven records:** patient, staff and hospital data managed through MySQL
- **Role-based access:** users only see the pages and actions that belong to their role

## 🛠 Tech stack

| Area | Tools |
|---|---|
| Backend | PHP |
| Database | MySQL |
| Frontend | HTML, CSS, JavaScript |
| Local server | XAMPP |

## 🚀 Run it locally (XAMPP)

1. Install [XAMPP](https://www.apachefriends.org/) and start **Apache** and **MySQL**.
2. Copy this project folder into `C:\xampp\htdocs\hospital-management-system`.
3. Open **phpMyAdmin** (`http://localhost/phpmyadmin`), create a database, and import the `.sql` file from this repository.
4. Open the database config file and replace every placeholder with your own database details.
5. Visit `http://localhost/hospital-management-system` in your browser.

## 🔐 Privacy and security

This repository contains **no real patient, staff or hospital data**. Any records in the database file are fictional demo data, and all passwords and keys are placeholders.
